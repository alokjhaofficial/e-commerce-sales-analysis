# E-Commerce Sales Analysis Dashboard

## 📊 Project Overview

This is a beginner-level E-Commerce Sales Analysis project created using Excel/Google Sheets.

The goal was to analyze 300 e-commerce orders and identify sales trends, top-performing products, category performance, and monthly sales patterns.

## 🛠️ Tools Used

- Microsoft Excel / Google Sheets
- Pivot Tables
- Charts
- Basic Data Analysis
- KPI Calculations

## 📈 Key KPIs

- Total Sales: ₹83,97,092.50
- Total Orders: 300
- Average Order Value: ₹27,990.31
- Top Product: Laptop
- Top Category: Electronics
- Best Month: March

## 🔍 Key Insights

- Electronics contributed approximately 75% of total sales.
- Laptops generated the highest product-level revenue.
- March was the best-performing month.
- The dashboard provides a quick overview of overall sales performance.
